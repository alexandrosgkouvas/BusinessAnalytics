📤 Upload Your Dataset

💡 Instructions

  • Select a file (CSV, Excel, or TXT) to upload.
  • If the file has more than 50,000 rows, you’ll be asked to sample it.
  • After processing, you’ll get a preview and download link.

📘 SAS PROC Details

Use the following code to import your sampled dataset into SAS ODA:

PROC IMPORT DATAFILE="/home/yourname/sampled_file.csv"
    OUT=work.mydata
    DBMS=CSV
    REPLACE;
    GETNAMES=YES;
RUN;
